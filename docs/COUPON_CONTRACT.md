# 무상 쿠폰 계약

## 정책

| 정책 | 구현 규칙 |
| :--- | :--- |
| 쿠폰 성격 | 이벤트·보상용 무상 쿠폰만 지원. 현금 환급·양도·연장 불가 |
| 표시 조건 | 제목, 할인액, 최소 주문금액, 발급/만료 시각, 중복 사용 불가를 사용자 화면에 표시 |
| 할인 | 정액 할인만 지원. 할인액은 서버가 `min(discountAmount, itemsAmount + deliveryFee)`로 확정 |
| 사용 시점 | 주문 매칭 요청 생성 중 사용자 쿠폰을 잠금 조회해 `APPLIED` 상태와 주문 연결을 하나의 트랜잭션으로 처리 |
| 복구 | 결제 전·결제 직후 취소로 주문이 `CANCELLED`되면 연결 쿠폰을 한 번만 `AVAILABLE`로 복구. 환불·클레임에는 복구하지 않음 |
| 만료 | 만료 시각 이후에는 사용 불가. 배치·조회 시 `EXPIRED`로 정리 |
| 감사 | 발행·적용·복구·만료를 `coupon_events`에 append-only로 기록 |

## V12 스키마

```sql
create table coupons (
  id bigint generated by default as identity primary key,
  code varchar(40) not null unique,
  title varchar(100) not null,
  discount_amount integer not null check (discount_amount > 0),
  minimum_order_amount integer not null check (minimum_order_amount >= 0),
  starts_at timestamptz not null,
  expires_at timestamptz not null,
  active boolean not null default true,
  created_by bigint references users(id),
  created_at timestamptz not null,
  constraint ck_coupon_period check (expires_at > starts_at)
);
create table coupon_issues (
  id bigint generated by default as identity primary key,
  coupon_id bigint not null references coupons(id),
  consumer_id bigint not null references users(id),
  status varchar(20) not null,
  applied_order_id bigint unique references orders(id),
  issued_at timestamptz not null,
  applied_at timestamptz,
  restored_at timestamptz,
  expires_at timestamptz not null,
  constraint ck_coupon_issue_status check (status in ('AVAILABLE','APPLIED','EXPIRED','CANCELLED'))
);
create table coupon_events (
  id bigint generated by default as identity primary key,
  coupon_issue_id bigint not null references coupon_issues(id),
  event_type varchar(30) not null,
  actor_user_id bigint references users(id),
  detail varchar(500) not null,
  created_at timestamptz not null
);
alter table orders add column coupon_issue_id bigint unique references coupon_issues(id);
```

## REST

| API | 권한 | 처리 |
| :--- | :--- | :--- |
| `GET /api/coupons/mine` | 소비자 | 사용 가능·적용·만료 쿠폰 조회 |
| `POST /api/admin/coupons` | 관리자 | 쿠폰 정책 생성 |
| `POST /api/admin/coupons/{couponId}/issues` | 관리자 | 특정 사용자에게 쿠폰 발행 |
| `GET /api/admin/coupons` | 관리자 | 정책·발행 현황 조회 |
| `POST /api/orders` + `couponIssueId` | 주문자 | 서버 할인 확정·쿠폰 적용·주문 연결 |

## 테스트 조건

1. 만료·비활성·최소 주문금액 미달·타인 쿠폰·재사용은 서버가 거부한다.
2. 주문 생성과 쿠폰 `APPLIED` 전이는 하나의 트랜잭션이다.
3. 주문 취소를 반복해도 쿠폰은 한 번만 복구된다.
4. 클라이언트 `discountAmount`는 쿠폰 할인으로 사용되지 않으며, 서버 확정 값만 주문에 저장한다.
