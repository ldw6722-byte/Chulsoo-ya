# 인증 화면 시각 검증 메모

- 검증 경로: `http://localhost:5173/auth/login`, `http://localhost:5173/auth/signup`
- 로그인: 보관된 체크 테두리 메인 로고가 상단 홈 링크로 표시되고, 카드·소셜 버튼·폼·테마 전환이 한 화면에 표시됐다.
- 회원가입: 현재 브라우저 환경에서 문서 아래로 49px가 남아 스크롤이 발생했다.
- 원인: 가입 전용 저높이 미디어 쿼리가 현재 브라우저의 CSS 뷰포트 높이에 일치하지 않아, 가입 카드와 테마 전환의 압축 규칙이 적용되지 않았다.
- 보정 방향: 가입 전용 축소 규칙을 높이 미디어 쿼리 밖으로 이동하고, 테마 전환을 화면 하단 고정으로 처리해 카드 입력·약관·제출·로그인 링크를 한 화면에 유지한다.
