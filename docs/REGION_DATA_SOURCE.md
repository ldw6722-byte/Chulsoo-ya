# 전국 시군구 지역 코드 데이터 기준

## 단일 기준

철수야의 판매점 등록·매칭·탐색 지역 코드는 **국토교통부 법정동 코드**에서 현재 존재하는 시도·시군구 단계를 추출해 사용한다. 카카오 주소 검색은 사용자가 주소와 장소를 찾는 입력 도구이며, 최종적인 지역 식별자는 서버가 DB의 공식 코드와 주소의 시도·시군구명으로 대조해 결정한다.

| 구분 | 기준 |
|---|---|
| 공식 원천 | [행정표준코드관리시스템 법정동 코드](https://www.code.go.kr/stdcode/regCodeL.do) 및 [국토교통부 법정동 코드 파일](https://data.go.kr/data/15123287/fileData.do) |
| DB 저장값 | 공식 법정동 코드의 시군구 수준 5자리 코드와 시도명·시군구명 |
| 대상 | 현재 존재하는 전국 시도·시군구. 제주특별자치도 및 그 하위 지역은 서비스 지역에서 제외 |
| 주소 입력 | 카카오 주소·장소명 검색 결과의 시도·시군구명을 서버가 DB 지역 마스터와 대조 |
| 매칭 | `stores.gu_code`는 지역 마스터의 코드만 저장. 주소 문자열 해시나 프론트 임의 문자열은 사용하지 않음 |

## 근거

행정표준코드관리시스템은 법정동 코드와 명칭을 시도·시군구·읍면동 등 계층으로 제공한다. 국토교통부 법정동 코드 파일은 이 목록을 원천으로 하며, 현존·폐지 여부와 지역 코드 매칭 용도로 제공된다.[1] [2]

## 적용 원칙

1. 판매자 신청의 시도·시군구 입력은 직접 입력하지 않는다.
2. 판매점 생성·수정·관리자 등록은 지역 마스터에서 선택되거나 카카오 주소 결과로 서버 해석된 지역만 허용한다.
3. 기존 해시형 `GU_XXXX` 값은 신규 등록에 사용하지 않으며, 별도 마이그레이션 단계에서 공식 코드로 정규화한다.
4. 지역 마스터에서 제외된 제주 주소는 일반 배송 주소로는 보존할 수 있으나 판매점 등록·매칭 지역으로는 승인하지 않는다.
