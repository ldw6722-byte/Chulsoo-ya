# Kordeal UI 이식 기준

## 공통 셸

| 영역 | 확인된 Kordeal 구조 | 철수야 이식 방식 |
| :--- | :--- | :--- |
| 상단 유틸리티 | 마이페이지·로그인·회원가입·관리자 바로가기 | 철수야 역할·인증 상태에 맞는 바로가기 유지 |
| 메인 헤더 | 카테고리 버튼, 브랜드 로고, 넓은 검색 입력창, 검색 버튼, 계정/장바구니 아이콘 | `AppShell` 공통 헤더로 이식, 검색은 철수야 `/catalog?q=`와 연동 |
| 퀵 내비게이션 | 배송·특가·인기·신상품 등의 가로 메뉴 | 철수야 카테고리·매칭 안내·인기 공구·신규 상품 메뉴로 변환 |
| 푸터 | 고객·쇼핑·판매자·회사 안내 4열 | 철수야 고객센터·주문·판매자 운영·정책 링크 구조로 재사용 |

## 메인 페이지

Kordeal은 상단 대형 검색 및 프로모션 히어로, 카테고리 아이콘 그리드, 상품 섹션 순으로 구성된다. 철수야는 같은 시각적 계층을 사용하되 브랜드·도메인 문구를 철물·공구·주문 매칭에 맞게 변경한다.

## 마이페이지

| 영역 | Kordeal 구조 | 철수야 적용 |
| :--- | :--- | :--- |
| 헤더 카드 | 보라색 그라데이션의 사용자/혜택 요약 | 철수야 블루 기반 프로필·주문·장바구니 요약 |
| 좌측 메뉴 | MY 쇼핑·혜택·활동·정보로 구분된 섹션 메뉴 | 주문/매칭·쿠폰·관심상품·계정/배송지로 재구성 |
| 상태 요약 | 주문 중·배송 중·장바구니·쿠폰 카드 4개 | 요청 중·매칭 중·진행 주문·장바구니 카드 |
| 본문 | 최근 주문 빈 상태/주문 목록 영역 | 철수야 최근 주문 및 매칭 상태 목록 |

## 페이지별 이식 대상

- `/signin`, `/signup`: 공통 쇼핑 앱 셸과 본문 카드 기반 인증 화면.
- `/cart`, `/checkout`, `/payment`: Kordeal 장바구니·주문·결제의 정보 계층과 우측 요약 패널을 철수야 REST 계약에 연결.
- `/admin`: Kordeal 관리자 정보 밀도와 테이블/요약 카드를 철수야 지표·판매자/주문 데이터로 변환.

> Kordeal 브랜드·법인 정보·상품 도메인 문구는 복제하지 않고, 철수야의 공구 매칭 플랫폼 문구·API·상태값으로 치환한다.
