# 모바일 인증 화면 검증 결과

검증 뷰포트는 Chrome DevTools 모바일 에뮬레이션의 390×844px이며, 문서 폭과 뷰포트 폭은 모두 390px으로 측정됐다. 로그인과 회원가입 모두 인증 카드와 입력 필드가 뷰포트 안에 완전히 들어오며 가로 넘침은 없다.

인증 폼을 세로 플렉스 컨테이너로 보정해 입력 필드·약관·제출 버튼 블록의 15px(약 4mm) 이격이 실제 레이아웃에도 적용된다. 구글 버튼의 1px 중립 테두리, 카카오 버튼의 1px 올리브 테두리, 입력 필드 테두리는 라이트·다크 화면의 390px 폭에서 모두 식별 가능하다.

로그인은 현재 뷰포트에서 전체가 보인다. 회원가입은 44px 이상 터치 영역과 모든 가입 필드를 유지하기 위해 하단 제출·테마 영역으로 짧은 세로 스크롤이 필요하다.
